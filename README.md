A full-stack E-commerce web application designed for efficient product management and real-time user interaction. Built with **Server-Side Rendering (SSR)**, this platform prioritizes performance, SEO friendliness, and smooth data flow.

🔗 **Live Demo:** [https://product-management-lilac.vercel.app/](https://product-management-lilac.vercel.app/)

---

## 🚀 Key Features

* **Comprehensive Product Management:** Full CRUD (Create, Read, Update, Delete) functionality for managing a product catalog.
* **Real-time Communication:** Integrated **Socket.io** to enable instant chat functionality between users.
* **High Performance SSR:** Utilizing Server-Side Rendering for faster initial page loads and better search engine visibility.
* **Secure Data Handling:** Robust backend integration with **MongoDB** for persistent and scalable data storage.
* **Responsive UI:** A clean, professional interface that works seamlessly across mobile, tablet, and desktop devices.
* **Real-time Updates:** Dynamic UI updates without requiring page refreshes for critical interactions.

---

## 🛠 Tech Stack

### Backend & Infrastructure
-   **Runtime:** Node.js
-   **Framework:** Express.js
-   **Database:** MongoDB (via Mongoose ODM)
-   **Websockets:** Socket.io
-   **Deployment:** Vercel

### Frontend
-   **Rendering:** SSR (Template Engine)
-   **Logic:** JavaScript (ES6+)
-   **Styling:** HTML5, CSS3

## 📦 Getting Started

To run this project locally, follow these steps:

### 1. Prerequisites
-   Node.js (v14 or higher)
-   MongoDB account (Atlas or local)

### 2. Installation
```bash
# Clone the repository
git clone [https://github.com/nguyendangcuong201004/product-management.git](https://github.com/nguyendangcuong201004/product-management.git)

# Navigate to the project directory
cd product-management

# Install dependencies
npm install
